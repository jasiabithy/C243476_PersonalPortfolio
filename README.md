# Jasiatul Hikma Bithy | Graphic Design Portfolio

A responsive, single-page graphic-design portfolio that can be published directly with GitHub Pages. No build step is needed.

## Personalize before publishing

Open `index.html` and replace the starter contact and portfolio details:

- Replace `your-email@example.com` with your real email address.
- Replace `yourusername` in the Instagram links with your account name, or remove the links you do not use.
- Replace the six sample project names, descriptions, and inspiration photos with your own design work. The current images are examples, not claims of completed client projects.
- Review the service and package prices. They are editable USD starting-price examples; adjust them to match your rates and scope.
- Add your Student ID where needed for your class submission and repository naming.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `StudentID_PersonalPortfolio`, replacing `StudentID` with your own ID (example: `C223123_PersonalPortfolio`).
2. Add `index.html` and `README.md` to the repository root and push them to the `main` branch.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Wait for GitHub Pages to publish. The website URL will look like `https://YOUR_GITHUB_USERNAME.github.io/StudentID_PersonalPortfolio/`.
5. Check that both the public repository URL and the published website URL open, then submit both links through Google Classroom.

The page uses Google Fonts and sample photos hosted externally, so those assets need an internet connection. The site itself is plain HTML, CSS, and JavaScript.
