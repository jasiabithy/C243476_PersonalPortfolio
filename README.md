# Jasiatul Hikma Bithy | Graphic Design Portfolio

A responsive, single-page graphic-design portfolio that can be published directly with GitHub Pages. No build step is needed.

## Personalize before publishing

Open `index.html` and replace the remaining starter portfolio details:

- The contact email is set to `jasiabithy6@gmail.com`.
- Replace `yourusername` in the Instagram links with your account name, or remove the links you do not use.
- The gallery contains four beginner practice concepts: a logo, cafe menu, social post, and event poster. Replace them with your own work as you create it.
- Review the service and package prices. They are editable USD starting-price examples; adjust them to match your rates and scope.
- Student ID: `C243476`.

## Publish with GitHub Pages

The public repository is `https://github.com/jasiabithy/C243476_PersonalPortfolio/` and the live site is `https://jasiabithy.github.io/C243476_PersonalPortfolio/`.

To publish future edits, run `git add index.html README.md`, `git commit -m "Update portfolio"`, and `git push` from this folder. GitHub Pages deploys from `main`.

The page uses Google Fonts and a sample hero photo hosted externally, so those assets need an internet connection. The practice project previews are built with HTML and CSS; the site needs no build tool.
